Phase 2 palletizing cell: full pick-and-place on the ROS 2 / MoveIt 2 stack.
Recorded 2026-07-26. ROS 2 Jazzy, Ubuntu 24.04, mock hardware, headless.

    ros2 launch armik_moveit ur5e_gripper_moveit.launch.py launch_rviz:=false
    ros2 run armik_moveit palletize

The UR5e transfers 4 parts from the supply bin to a 2x2 pallet, routing every
transfer through a high waypoint above the machine fixture, gripping with the
Robotiq 2F-85, and filling the pallet back-to-front so no placement reaches over
an already-placed part. Parts move as attached collision objects (mock hardware
has no physics grasp).

Run:

      part_3: bin (0.51, -0.24) -> pallet slot (0.52, 0.25)

    === palletizing metrics ===

    cycle time   : ~50-85 s/part (mock hardware, includes OMPL planning + retries)

Features: parametric bin->pallet transfer, multi-layer capable (LAYERS), a
reachability pre-check that rejects out-of-workspace slots, gripper pick/place,
and production-style metrics. This is the ROS/MoveIt version of the Phase 1
