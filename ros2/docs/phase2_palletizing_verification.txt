Phase 2 palletizing cell: industrial pick-and-place on ROS 2 / MoveIt 2.
Recorded 2026-07-26. ROS 2 Jazzy, Ubuntu 24.04, mock hardware, headless.

    ros2 launch armik_moveit ur5e_gripper_moveit.launch.py launch_rviz:=false
    ros2 run armik_moveit palletize

Approach (see docs/ENGINEERING_PLAN.md):
  - Consistent top-down grasp: each station's joint config from one /compute_ik
    seed, so the tool always arrives straight down in the same posture.
  - OMPL obstacle-avoiding transfers to those joint configs (routes around the
    separator); Pilz LIN straight-line descents/retreats.
  - Part attached at the true grasp offset (tool-z down), so it stays exactly
    where it sat, no teleport.
  - Reachability pre-check; back-to-front pallet filling; metrics.
